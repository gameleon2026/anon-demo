Gameleon
Gaussianizing Point Clouds for
On-Demand 4D Performance Over the Air

The first compressed 3D data-to-Gaussians coding system for real-time playback. The system changes the terminal decoded representation from reconstructed colored point clouds to Gaussian primitives, allowing the compressed representation to directly serve the final screen-space display.

Visual Demonstrations

This page presents the results of Gameleon, including both static and dynamic showcases. The static showcase supports free-viewpoint viewing, while the dynamic showcase is presented as videos only due to web resource limitations.
